✨ Key Features

1. Hybrid Detection System

Combines statistical baseline learning with LLM reasoning:

  • Statistical Baselines: Learn normal patterns from training data
  • Anomaly Scoring: Calculate deviation scores (0.0 to 1.0)
  • LLM Analysis: Determine if anomalies are real threats
  • Context-Aware: Uses historical data and cross-agent correlation

2. MITRE ATT&CK Integration

Full integration with MITRE ATT&CK framework:

  • Graph Database: Neo4j stores MITRE techniques and relationships
  • Vector Search: Semantic matching of observations to techniques
  • Proactive RAG: Pre-fetches related techniques for early warning
  • Technique Mapping: Automatically maps detections to MITRE techniques

3. Real-Time Communication

Agent collaboration and real-time updates:

  • Message Bus: Redis-based pub/sub for agent communication
  • WebSocket: Real-time updates to frontend
  • Agent Collaboration: Agents query each other for context
  • Cross-Agent Correlation: Identifies coordinated attacks

4. Action Guardrails

Complete user control over agent actions:

  • Action Interception: All actions intercepted before execution
  • User Approval: Required for all agent actions
  • Policy Engine: Configurable policies for different actions
  • Audit Trail: Complete logging of all actions and decisions

5. Baseline Training System

Statistical baseline learning from training data:

  • Numeric Baselines: Mean, std dev, percentiles for numeric features
  • Pattern Baselines: Frequency-based patterns for categorical data
  • Training Modes: Training, inference, and hybrid modes
  • Metrics: Detailed statistics and readiness indicators

6. Attack Testing Framework

Comprehensive attack generation and testing:

  • LLM-Powered Generation: Realistic attack scenarios
  • MITRE-Based Attacks: Attacks mapped to MITRE techniques
  • Auto-Testing: Automatic agent and attack type selection
  • Result Analysis: Detailed test results and metrics

🚀 Getting Started

Prerequisites

  • Python 3.8+
  • Redis (for message bus)
  • Neo4j (for MITRE ATT&CK knowledge base)
  • OpenAI API key (or other LLM provider)

Installation Steps

# Install dependencies pip install -r requirements.txt # Start Redis redis-server # Start Neo4j (using Docker) docker run -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/password neo4j:latest # Start backend server python start_backend_server.py # Start frontend server python -m http.server 8080
